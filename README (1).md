
# Predictive Analytics Using Historical Data

## Project Overview
This project analyzes historical airline passenger data
and predicts future passenger counts using Machine Learning.

## Objectives
- Clean and preprocess historical data
- Analyze passenger trends
- Train a Linear Regression model
- Evaluate prediction accuracy
- Forecast passenger counts for the next 12 months

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Algorithm
Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared Score

## Project Files
- Predictive_Analytics.ipynb
- Model_Evaluation_Results.csv
- Future_Passenger_Forecast.csv
- Actual_vs_Predicted.csv

## Conclusion
This project demonstrates forecasting using historical
data. Predictions are estimates and may not capture
all seasonal variations.
